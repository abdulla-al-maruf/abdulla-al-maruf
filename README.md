## Things I've built

### [EmailFilter](https://github.com/abdulla-al-maruf/EmailFilter)

Paste a messy list, a CSV, or an Excel file and it pulls out every email
address, then checks whether the domain can actually receive mail. Runs
in the browser, nothing gets uploaded. Free, no signup.

**[→ Try it](https://abdulla-al-maruf.github.io/EmailFilter/)**

### [WA Client Exporter](https://github.com/abdulla-al-maruf/wa-client-exporter)

An Android app that exports WhatsApp chats with everything intact: images,
replies, reactions, voice notes and their transcripts. WhatsApp's own export
throws most of that away. I needed full client conversations I could hand to
an AI, so I built this. Needs a rooted phone.

### [VCamdroid](https://github.com/abdulla-al-maruf/VCamdroid)

Turns an Android phone into a Windows webcam. Started as someone else's
project. I rebuilt the UI, made 1080p the default, and added noise-cancelled
audio, a background service, and auto-connect.
